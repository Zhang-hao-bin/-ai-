# 生活书房 · 人生决策参考助手

基于《高性价比人生指南》的第一版知识库问答应用。后端 Python + FastAPI，回答链使用 LangChain Core + ChatOpenAI；前端为原生 HTML/CSS/JavaScript。

把生活中的困惑说具体，先找到依据，再一起想清楚下一步。助手采用资深、富有同情心的学者角色，用自然的语言解释建议，并提供可以展开核对的原文引用。

## 本地启动

安装 [uv](https://docs.astral.sh/uv/) 后，在本目录运行：

```bash
uv sync --group dev
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000 。没有模型配置时，可以直接查原文。

## 接入模型

复制 `.env.example` 为 `.env`，填入服务商提供的值：

```dotenv
LLM_API_KEY=你的密钥
LLM_MODEL=服务商提供的模型标识
LLM_BASE_URL=服务商的兼容接口地址
```

`LLM_BASE_URL` 可留空以使用 ChatOpenAI 默认地址。其他服务需支持 OpenAI 兼容的 Chat Completions 和 JSON 输出模式；未验证所有提供商的兼容性。密钥只在服务器读取，不放到网页中、不提交到 Git。

重启服务后生效。启用后，每次生成回答会向所配置服务商发送用户问题、有限的对话上下文及检索到的正文，可能产生模型费用。后端不保存聊天记录。前端通过 localStorage 将完整消息、引用和输入草稿保存在当前浏览器；每次请求可发送当前会话最近 1000 条有效消息（单条最多 4000 字符），后端按配置的 token 容量裁剪最早消息，并为回答预留空间。vLLM 通过 `/tokenize` 准确计数；未配置分词接口时用 UTF-8 字节数保守估算。清除网站数据或浏览器存储会删除记录，隐私模式下记录可能只保留到窗口关闭；不同设备和浏览器之间不会同步，也不支持多个浏览器标签页同时编辑记录。

## 内置技能与回答方式

`app/skill.py` 将 life-decision-guide 的完整条目核对、成本收益比较、证据等级、适用条件和风险判断适配为应用内指令，`app/service.py` 在创建回答链时加载它。原始 skill 保留在 `prompts/original-skill.md` 供对照；原 skill 中的命令由本地检索与知识同步工具承担，模型没有联网或执行 shell 的工具。

`prompts/system.md` 定义资深、富有同情心的学者角色。有相关知识时用自己的话解释并引用原文；没有相关条目时正常交流，提供一般知识或建议，不能冒充书中结论。问候不强行引用，也不再被“没有检索结果”拦截。虚构或不一致的引用仍会被校验拒绝。模型未配置或暂时不可用时，系统如实提示状态，不伪装成 AI 回答。

## 导入更多正文

停止服务后执行：

```bash
uv run python scripts/sync_knowledge.py
```

如果 GitHub 网络不可用，先通过其他方式下载/解压仓库，再执行：

```bash
uv run python scripts/sync_knowledge.py --source /absolute/path/to/HowToLiveBetter
```

同步保留原条目，不执行上游代码。成功后重启服务。初始节选没有固定提交 SHA，后续 Git 导入会记录提交身份；本地目录导入不保证已更新到最新政策。
